# Pet-проекты

Здесь собраны мои учебные проекты по анализу данных.  
В каждом проекте я старался пройти полный цикл: от загрузки и очистки данных до визуализации, проверки гипотез и формулирования выводов.

---

## [Online retail](https://github.com/Mindalmilk/pet-projects/tree/main/online-retail)
Анализ розничных продаж интернет-магазина.

- Загружены и изучены данные о транзакциях
- Визуализированы общие метрики покупок, распределение по странам, покупателям, времени суток, дням недели и месяцам
- Проведён когортный анализ удержания клиентов
- Выполнена RFM-сегментация пользователей для выявления ценных групп

**Технологии:** Python, NumPy, Pandas, Jupyter Notebook, Matplotlib, Seaborn

## [S7 Dashboard](https://github.com/Mindalmilk/pet-projects/tree/main/S7_dashboard)
Построение дашборда для визуализации ключевых экономических показателей.

- На основе предоставленных данных рассчитаны основные финансовые метрики
- Выбран оптимальный тип визуализации и аккуратно оформлен итоговый дашборд

## [AB-test](https://github.com/Mindalmilk/pet-projects/tree/main/AB-test)
Планирование, проведение и анализ A/B-теста.

- Сформулированы продуктовая и статистическая гипотезы
- Определён минимально необходимый размер выборки для эксперимента
- Проведена статистическая обработка результатов и интерпретирован исход теста

**Технологии:** Python, NumPy, Pandas, Jupyter Notebook, SciPy, Statsmodels

---

## [funnel_analysis](https://github.com/Mindalmilk/pet-projects/tree/main/funnel_analysis)
Анализ воронки продаж и конверсии пользователей.

- Выполнена первичная обработка данных, визуализирована активность клиентов по дням недели и другим параметрам
- На основе логов действий построена, визуализирована и проанализирована воронка продаж (от корзины до заказа)
- Сформулирована и проверена гипотеза о зависимости конверсии в покупку от канала трафика

**Технологии:** Python, NumPy, Pandas, Jupyter Notebook, Matplotlib, Seaborn, Plotly, SciPy
